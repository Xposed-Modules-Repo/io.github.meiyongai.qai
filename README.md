# QAI

QQ 聊天 AI 助手。长按选中消息，结合聊天背景、引用内容和角色风格生成回复候选，由你选择插入或发送。

[下载最新版本](https://github.com/Xposed-Modules-Repo/io.github.meiyongai.qai/releases/latest) · [源码与详细说明](https://github.com/MeiYongAI/QAI) · [更新日志](https://github.com/MeiYongAI/QAI/blob/main/CHANGELOG.md) · [问题反馈](https://github.com/MeiYongAI/QAI/issues)

## 兼容范围

- Android 8.0（API 26）及以上。
- 支持 LibXposed API 102 的框架。
- **仅适配 QQ 9.3.55（versionCode 15900）**，包名 com.tencent.mobileqq。
- 支持好友私聊与群聊，不支持频道。
- 使用兼容 OpenAI Chat Completions 且支持 JSON Output（json_object）的接口与模型。

## 安装与使用

1. 从发布页下载 APK 并安装，在模块管理器中启用 QAI，作用域勾选 QQ，然后重启 QQ。
2. 进入 QQ 设置中的 QAI，配置接口地址、密钥、模型与角色。
3. 长按要回复的消息，点击 QAI，等待生成候选。
4. 选择候选后点击“插入”或“发送”。插入仅填入输入框，发送调用 QQ 消息接口；生成不会自动发送。

模块没有独立桌面图标，设置入口位于 QQ 内。正式版本延续已有签名，升级后需要重启 QQ。

## 1.2.0 的主要变化

- 围绕选定目标检索相关聊天背景，按需展开引用、聊天记录卡片与图片。
- 持续维护实际观察到的消息资料，按账号和会话隔离；仅在 QQ 确认发送后写入回复记忆。
- 保留说话人、原生 @、引用作者与当前账号身份，区分原交谈对象和主动参与回复的人。
- 一次成功响应生成完整候选列表，条数由 AI 决定，成功结果必须非空。
- 上下文理解只消费约定字段，额外 JSON 成员不进入计划和记忆；来源 ID 等必要校验保留。
- 回复窗口采用 QQ 主题配色和紧凑底部布局，思考时滚动展示，完成后收起显示耗时。
- 支持多套自定义接口、多条密钥及不可用密钥轮换。
- 点击发送后立即启动收起动画，发送结果单独确认和反馈。

主模型支持视觉时可直接接收选中的图片，也可配置独立视觉接口先获取描述。模型能力以所配置服务为准。

## 使用边界

聊天文本和选中的图片会发送到你配置的 AI 接口；API 调用费用由对应服务商收取。模块只保存实际接收到或观察到的聊天资料，不自动全量读取账号历史。

已完成自动化测试和实际设备迭代测试，但引用与转发的全部组合、不同模型和 QQ 主题尚未全面验收。QQ 已撤回、过期或拒绝返回的内容无法保证读取。遇到发送未确认时请先检查聊天记录，避免重复发送。
